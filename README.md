# The Periodic Table of Indian Fashion

A single-page website that lays out 50 trending Indian fashion elements as a periodic table, from Lucknow chikankari and Kolhapuri chappals to cargo pants and co-ord sets.

- **Columns are families**: Gen-Z Streetwear, Indo-Western Fusion, Handloom & Textiles, Ethnic Silhouettes, Jewellery, Footwear & Bags, Beauty & Adornment, and Timeless Classics (column 18, the "noble" elements that never react to trends).
- **The Shaadi Series** is the detached bottom row of wedding-season elements.
- Click an element to see where it's trending, a short description, a styling tip and its Hype index (an editorial score, not measured data).
- Filter by family or search by name, place or craft.

## Run it

No build step. Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → deploy from the `main` branch) to host it.
